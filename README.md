# Invictus Frontend

**Unconquered. Always Forward.**

Your personal command center for goals, plans, and progress.

## Development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` and configure `VITE_API_BASE_URL` for the FastAPI backend.

## Production

```bash
npm run build
```

Deploy the generated `dist` directory to Cloudflare Pages or another static host.
